# 伊犁旅行现场避坑笔记

记录时间：2026-06-29

用途：先保存旅途中真实体验和避坑点，后续可整理成游记、攻略复盘或路线修正版。

## 已确认避坑点

1. D1 乌鲁木齐/S101/安集海这段不是所有人都值得走。
   - 如果不喜欢戈壁滩、丹霞、荒原风貌，第一天可以不走 S101 和安集海，直接去赛里木湖。
   - 如果从北京出发，可以考虑直接飞伊宁。这样能把更多时间留给赛里木湖，赛湖游玩会更从容。
   - 后续写游记时可以把这段写成“适合人群”：喜欢公路、荒野、丹霞的人适合；只想看湖泊草原的人可以跳过。

2. D2 赛里木湖景区内有房车住宿。
   - 现场观察：景区内有房车，理论上应该可以通过渠道订到。
   - 如果目标是看星星，必须先看天气。云量、月相、风和夜间温度都会影响体验。
   - 后续需要补充：可订渠道、价格区间、房车位置、是否含景区门票/车辆进入规则。

3. D3 果子沟/霍城方向可以精简。
   - 晃晃村可以去。
   - 薰衣草看核心区域即可，不一定要专门去霍城县城或拉长停留。
   - 后续游记建议写成：D3 重点放在“赛湖补拍 + 果子沟 + 晃晃村 + 薰衣草”，霍城不作为必须打卡点。

4. 阔克苏大峡谷可降级或不去。
   - 现场体验：意义不大，体验感不高。
   - 后续修路线时可以考虑：喀拉峻保留草原线，阔克苏从主线拿掉，改成“时间富余/第一次来/特别想看峡谷地貌再选”。
   - 如果拿掉阔克苏，D6 可以更轻松地从喀拉峻/特克斯方向推进到新源或那拉提附近。

5. 喀拉峻草原强烈建议住景区。
   - 现场体验：喀拉峻草原住在景区里非常漂亮，应该作为强推荐，而不是普通住宿建议。
   - 可以在鲜花台找拼车去库尔代河谷，风景非常漂亮。
   - 后续修路线时要把“喀拉峻住景区 + 鲜花台拼车去库尔代河谷”写成核心体验；阔克苏可以让位给这段。

## 后续整理方向

- 把“规划时看起来值得”和“现场实际值得”分开写。
- 每天增加一个“适合谁 / 不适合谁”的判断。
- 把路线建议分成两版：第一次来打卡版、轻松少踩坑版。
- 对每个景点补充真实体验权重：必去、可去、路过、可跳过。
- 喀拉峻部分重点写景区住宿、鲜花台、库尔代河谷拼车体验。
